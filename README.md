# Step 2: Initialize Git in Your Local Folder

1. Open your terminal or command prompt
2. Navigate to your project folder:
```bash
cd path/to/your/project
```

3. Initialize the local Git folder:
```bash
git init
```

# Step 3: Add, Commit, and Push Your Files

1. Stage your files:
```bash
git add .
```

2. Commit your files with a message:
```bash
git commit -m "Initial commit"
```

3. Link your local folder to your online repository:
```bash
git remote add origin https://github.com/Custodio418/bootstrap5_Custodio.git
```

4. Set the main branch name:
```bash
git branch -M main
```

5. Push your files to GitHub:
```bash
git push -u origin main
```
